# Xapp mobile app

Expo (SDK 58) + Expo Router app. Routes live in `src/app/`; everything else outside it.

- Install packages with `npx expo install <pkg>` (add `EXPO_OFFLINE=1` if api.expo.dev is unreachable).
- All user-facing text goes through i18next (`src/i18n/locales/{en,fr,ar}.ts`). `en.ts` defines the shape; `fr` and `ar` must match it.
- Arabic is right-to-left. Use `Text` from `@/components/text` (handles alignment), `marginStart`/`paddingEnd` style props, and `useLanguage().rtl` for direction-dependent icons. Don't hardcode `left`/`right`.
- Colors come from `useColors()` in `src/theme.ts`; don't hardcode hex values in screens.
- Before finishing: `npm run typecheck` and `npx expo export --platform web` must succeed.
- Browser preview: `npx expo export --platform web --output-dir <dir>` then `python3 scripts/build-preview.py <dir> <out.html>` makes one self-contained page (async routes are off in `app.json` so the build is a single bundle). Inside it, `alert()` does nothing, so show messages in the page.
- Live data goes through `src/backend/`: a small `Store` interface (`store.ts`) with two implementations — `shared-store.ts` (the preview page's shared `db`, live across devices) and `local-store.ts` (on-device, live across browser tabs). Screens use `useDoc`/`useQuery` from `@/backend` and the functions in `backend/actions.ts`; a hosted backend (e.g. Supabase) should implement `Store`.
- Maps: `components/map/freight-map.tsx` (react-native-maps on phones) and `freight-map.web.tsx` (bundled Natural Earth shapes, since the preview can't load tiles). Places and search: `constants/places.ts`.
- Sounds: `lib/sounds.ts` (`play('tap' | 'send' | 'offer' | ...)`); files generated by `scripts/make-sounds.py`.
- `npm test` runs the pure logic tests (`src/lib/*.test.ts`).
- Trips run themselves from GPS: `lib/trip.ts` (`autoStatus`, reminders, levels, reliability — unit-tested). Drivers act with `SwipeButton` (slide to start / deliver); delivery closes with the client's 4-digit code. Trip events are written into the chat with `postEvent`.
- Booking reminders: in-app via `components/live-events.tsx`, and as phone notifications via `lib/notify.ts` (no-op on web).
- Media (voice notes, HD photos, videos): `lib/media.ts` (`captureMedia`, `storeFile`) and `components/media/` (recorder hook, player, gallery/viewer). In the preview, files go to the page's `assets` store and are referenced as `/_blob/<id>` (the db only keeps the URL; documents are capped at 256 KB). On phones they stay on the device until the hosted backend has file storage. The preview blocks the microphone, so the recorder falls back to choosing an audio file.
- Call / WhatsApp / maps buttons use `ExternalLink` (`components/external-link.tsx`): a real `<a href>` on web (the preview blocks opening links from code), `Linking` on phones.
- Vehicle pictures: `assets/images/vehicles/*.webp`, rendered with Blender by `scripts/render-vehicles.py` and packed by `scripts/pack-vehicles.py`; `vehicleImage(id)` in `constants/vehicles.ts`.
